# Naguminho: O Desafio — Versão final provisória V12

## Como testar no computador
Extraia o ZIP para uma pasta e abra `index.html`.

## Como publicar no GitHub Pages
Envie todos os arquivos para a raiz de um repositório público. Em Settings → Pages, escolha Deploy from a branch, branch `main` e pasta `/ (root)`. Aguarde a publicação e abra o link no computador ou celular.

## Dificuldade progressiva
A velocidade de queda aumenta com o tempo de sobrevivência e com a pontuação. Os objetos também aparecem com intervalos menores ao longo da partida, com limites para manter o jogo jogável.

## Mecânicas
- Pizzas pontuam e mostram as frases.
- Contrato da CET, Bob Esponja e Corinthians tiram uma vida.
- João Bolsonarista é um bônus raro e recupera uma vida, até o máximo de três.
- Matheus Petista causa derrota imediata.
- Recordes por nome são salvos localmente no navegador/dispositivo; não sincronizam automaticamente entre aparelhos.

Mantenha `index.html`, `style.css`, `game.js` e todas as imagens na mesma pasta.
